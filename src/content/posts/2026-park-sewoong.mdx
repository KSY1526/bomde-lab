// 피우르크: 100보다 높으면 타자 우세(붉은색), 낮으면 투수 우세(파란색). 100에서 멀어질수록 진하다
export const heat = (gap, step) => (gap === 0 ? null : { cls: gap > 0 ? 'up' : 'down', pct: [12, 24, 38, 52][Math.min(3, Math.floor((Math.abs(gap) - 1e-9) / step))] });
export const wrcTd = (r, y, showPa = true) => {
  if (!r) return <td class={yc(y)}>-</td>;
  const small = r.pa < d.small_pa;
  const h = heat(Math.round(r.wrc_plus - 100), 15);
  const cls = [yc(y), small ? 'small' : h ? h.cls : ''].filter(Boolean).join(' ');
  return <td class={cls} style={!small && h ? `--heat:${h.pct}%` : undefined}>{Math.round(r.wrc_plus)}{showPa ? ` (${r.pa})` : ''}</td>;
};

2021년 박세웅은 롯데 선발진의 중심이었다. 163이닝을 던져 평균자책점 3.98, WHIP 1.25를 기록했다. 박세웅을 상대한 타자의 우르크(wRC+), 즉 피우르크는 81로 리그 평균 타자보다 득점을 19% 덜 만들었다. 롯데는 2023년 시즌을 앞두고 박세웅과 5년 90억 원 계약을 맺었다.

그러나 계약 뒤 성적은 내리막을 탔다. 계약 첫해인 2023년 평균자책점 3.45로 반짝했지만 2024년 4.78, 2025년 4.93으로 올랐다. 2025년 피우르크는 110으로 박세웅을 만난 타자가 리그 평균보다 득점을 10% 더 만들었다. WHIP도 2021년 1.25에서 2025년 1.52가 됐다. 구단은 선발진을 이끌어 달라며 90억 원을 안겼는데 정작 계약 기간에 성적이 떨어졌다. 올해도 다르지 않았다. 평균자책점 4.71, 피우르크 110으로 2025년과 거의 같았고 3승 9패에 그쳤다.

## 5년 동안 동일했던 피칭 디자인

2021년부터 2025년까지 박세웅의 피칭 디자인은 일정했다. 포심과 슬라이더를 가장 많이 던지고 커브와 포크를 섞었다. 2023년 커터(5.2%), 2024년 체인지업(4.2%)을 잠깐 던졌지만 이듬해에는 사라졌다. 2025년에도 포심 40.0%, 슬라이더 32.3%, 포크 14.2%, 커브 13.5%로 네 구종이 전부였고 구사율도 유사했다.

## 윤석민의 조언 뒤 카운트별 구종 선택이 바뀌었다

박세웅은 2025년 시즌이 끝난 뒤 윤석민의 유튜브 채널에 나가 피칭 디자인 조언을 받은 일로 화제가 됐다. 타자가 노리는 코스를 피하고, 유리한 카운트에서는 존을 크게 벗어나는 공 대신 비슷한 코스로 던져 타자가 칠 범위를 좁히고, 존 안에서 타이밍을 뺏으라는 조언이었다. 그래서 올 시즌에 거는 기대가 컸다([관련 기사](https://osen.co.kr/article/G1112712572)).

조언을 들었는지는 카운트별 구종 선택에서 드러난다. 투수가 유리한 카운트에서 포크·커브 비중이 2021~2025년 51.1%에서 올해 38.0%로 줄었고 슬라이더 계열(슬라이더와 스위퍼)은 20.9%에서 33.5%로 늘었다. 초구(0-0)에는 포심이 47.4%에서 36.9%로 줄고 슬라이더 계열이 28.2%에서 39.9%로 늘었다. 투수가 불리한 카운트에서도 포심이 55.6%에서 45.1%로 줄었다. 어느 카운트든 포심이나 포크·커브를 던지던 자리에 슬라이더 계열이 들어갔다.

## 직구를 줄이고 스위퍼를 장착했다

직구 구사율을 전반적으로 줄이고 스위퍼를 장착했다. 포심 비율은 40.0%에서 35.5%로 2017년 이후 가장 낮다. 작년까지 한 번도 던지지 않은 스위퍼를 16.2% 던졌고 슬라이더는 32.3%에서 21.8%로 줄었다. 스위퍼는 평균 127.3km로 슬라이더 136.5km보다 9km 느리고 가로로 34.4cm 휜다. 가로 움직임이 6.5cm인 슬라이더와는 다른 공이다.

포크와 커브는 반대로 나빠졌다. 포크 피우르크는 2025년 46에서 올해 74로 올랐고 헛스윙률은 40.6%에서 33.3%로 떨어졌다. 커브는 2025년 7에서 올해 170이 됐다. 커브 피안타율이 .149에서 .396으로 뛰었다.

## 개선이 가장 필요한 것은 포크와 커브의 완성도

5년 동안 바꾸지 않던 피칭 디자인을 바꾼 첫해에 스위퍼는 박세웅 구종 중 피우르크가 상당히 낮은 플러스 피치가 됐다. 필자는 직구 구종 가치 상승과 스위퍼 추가의 이점을 살리고 좌타 상대 스플릿을 극복하려면 비시즌에 포크와 커브의 완성도를 높여야 한다고 생각한다. 내년 박세웅의 성적도 이 두 구종에 달려 있다.
